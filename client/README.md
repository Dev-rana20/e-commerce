# KÉLYS — Frontend Client Application

This is the React 19 + Vite frontend application for **KÉLYS Luxury Perfume E-Commerce Platform**.

For full project documentation, architectural overview, backend setup, and API references, please refer to the main [Root README.md](../README.md).

## 🚀 Quick Start (Frontend Only)

```bash
# Install dependencies
npm install

# Start development server (with HMR)
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🛠️ Key Libraries & Technologies
- **React 19** & **Vite 8**
- **Three.js** & **@react-three/fiber** (3D Perfume Bottle Shader)
- **Framer Motion 12** & **GSAP 3** (Animations)
- **Tailwind CSS v4** (Custom luxury color tokens)
- **Axios** (API Client with JWT handling)
